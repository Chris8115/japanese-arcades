# Groove Coaster cabinet

Groove Coaster is the fifth cabinet in the **Japanese Arcades** creative tab. It
uses the same three-part placement and native music-disc playback as the other
cabinets, with a substantially wider and deeper body. Its proportions are adapted
from the supplied photos rather than manufacturer measurements.

The design occupies about **1.52 blocks in width** and **1.65 blocks in depth**, with
a height just under three blocks. Placement uses one column of **three vertical
blocks**; the controller stand projects well in front of and beside that column.
Allow clear space for the whole cabinet, preferably two-block center spacing
between neighboring machines and an open aisle in front. The section selection
and collision shapes rotate with the cabinet. The base follows the foot platform,
two separated controller columns, and rear monitor tower, leaving the central
legroom open. The upper controller section uses a conservative selection box
around the projecting controls.

The display and controls are decorative. This cabinet plays Minecraft music discs;
it does not run a playable Groove Coaster game. The base emits light level 4 and
both upper sections emit level 13.

## Model and reference details

The supplied cabinet photos guide the classic blue/purple version: a tall portrait
monitor and shallow dot-matrix header, two illuminated cylindrical boosters with
layered black collars and silver buttons, a clear printed control bridge, curved
illuminated side cheeks, an angled card reader, coin mechanism, and metal platform.
The open space under the controls is actual geometry and collision clearance.
The screen, booster drums, header, and edge lighting use full-bright face data.

Compared at the same scale with our Chunithm model, Groove Coaster is approximately
**28% wider and 23% deeper**, while their headers remain at nearly the same height,
as in the supplied room photograph. This is an interpreted model scale rather than
a claim about manufacturer dimensions.

These studio previews render the exported cuboids and UVs. Studio illumination
differs from Minecraft lighting; shader bloom is not required by the model.

The portrait screen illustration was made with the built-in image-generation tool.
Its original PNG is retained unchanged in `display-artwork-source.png`, with the
exact prompt and provenance in [imagegen-prompts.txt](imagegen-prompts.txt).
The runtime texture pads the original pixels onto a power-of-two canvas and maps
them at their native aspect ratio. Hardware and branding atlases are generated by
`scripts/groove_coaster_textures.py`.

The export contains **4,441 elements and 5,993 rendered faces** across three block
models. An exterior-surface pass removes hidden and overlapping opaque faces. The
clear top-deck print is kept separate from that pass and uses mipmapped cutout
rendering. All rotations and section coordinates fit native Java block-model
limits; no custom rendering dependency is needed.

Regenerate with Python and Pillow:

```powershell
python scripts/make_groove_coaster_model.py
blender --background --python scripts/render_groove_coaster_model.py
blender --background --python scripts/render_arcade_scale_comparison.py
```

## Try it in Minecraft

Launch `dev.cmd Client` or `dev.cmd PackClient`, then choose **Groove Coaster Arcade
Cabinet** in the **Japanese Arcades** creative tab. Alternatively:

```text
/give @s japanesearcades:groove_coaster
```

Place it on a solid floor with three clear vertical blocks and room for the larger
body. Its front faces the player. Breaking any section removes the entire cabinet;
survival drops one cabinet item from the base.

Right-click any section while holding a music disc to insert one and start
playback. Right-click again to eject it. Each cabinet stores one disc and saves
the disc and playback progress. Registered modded songs with a valid
jukebox-playable component use the same native playback system. Breaking the
cabinet stops its song and returns the disc once, including creative removal.
Neighboring cabinets keep their own independent discs and playback. The base
provides jukebox redstone/comparator output and a one-slot container.
Ejected discs appear in the open footwell below the controller section, with their
full item bounding box clear of the cabinet's collision shapes.

Restart the development client after Java changes. F3+T reloads model and texture
changes only.

## Development and editing

The block/item ID is `japanesearcades:groove_coaster`. Registration starts in
`src/main/java/local/japanesearcades/JapaneseArcades.java`. `GrooveCoasterCabinetBlock.java`
supplies the larger section bounds and inherits placement and interactions from
`NostalgiaCabinetBlock.java`. All five cabinets use `NostalgiaJukeboxBlockEntity.java`
and Minecraft's native `JukeboxSongPlayer`; existing registry and saved-data IDs
are retained.

Model resources belong under `src/main/resources/assets/japanesearcades`. Artwork
generation prompts are saved in `imagegen-prompts.txt` in this directory. The
generator is the canonical model source: save manual Blockbench changes separately
or transfer them into the generator before regeneration, which replaces exported
model files.
