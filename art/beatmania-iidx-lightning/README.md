# beatmania IIDX LIGHTNING MODEL

The two-player LIGHTNING MODEL joins the Japanese Arcades creative tab and
the Arcade Ordering Kiosk as `japanesearcades:beatmania_iidx_lightning`.
It follows the supplied HEROIC VERSE references: a wide silver and black control
deck, two ring-lit turntables, two staggered seven-key banks, a sloped lower
touchscreen, a landscape main monitor, and tall forward-leaning purple light
columns. The raised standing platform, recessed lower speakers, center service
door, character banners, black upper backing, pale inner side panels and overhead
marquee complete the cabinet.

The turntables use a small native animated texture for subtle moving indicators.
The cabinet geometry remains static, without a custom renderer running every frame.
The screens and keys are decorative. Arcade Pass use simulates a result using
the existing credit and Prize Point system.

## Obtain and place

Order it for **24 iron ingots, 6 gold ingots, 2 diamonds, 8 glass, and 8 redstone**,
or use the Japanese Arcades creative tab:

```text
/give @s japanesearcades:beatmania_iidx_lightning
```

Provide a supported **two-block-wide, two-block-deep footprint**. The rear cabinet
stands three blocks high; the front row is a low, walkable standing platform.
The space above the platform stays open. The full assembly holds one saved disc
inventory, and breaking a section removes the connected cabinet.
The visible model measures **2 blocks wide, 2.99 high, and 1.98 deep**;
proportions are estimated from the supplied photographs.

Use an Arcade Pass for the shared simulated play and reward loop. The default
cost is 10 Credits; the server economy configuration can override this cabinet
using `japanesearcades:beatmania_iidx_lightning`. Insert and eject music discs with
the same right-click interactions as the other music cabinets.

These are original reference-inspired illustrations made with the built-in
imagegen tool. Source pixels are preserved when packing the runtime textures.
The character-banner source contains two adjacent illustrations, sampled through
separate UV regions. Utility labels, circuit trim, and turntable animation are
code-native textures generated by the model exporter.

The optimized item has **1,215 faces**; the eight world sections total
**1,494 faces** after splitting the mesh at block boundaries. Native chunk
rendering handles the geometry, with cached collision and selection shapes.
The 256-pixel turntable sprite uses 16 frames at 10 ticks per frame for an
eight-second loop. Illuminated surfaces are visible without shaders; bloom
depends on the active shader pack.

Regenerate the assets with `python scripts/make_iidx_model.py`, then run
`python scripts/optimize_models.py --write`. Studio previews and the packed Blender
scene use `scripts/render_iidx_model.py`. Ordinary builds use the checked-in
assets and do not require Python or Blender.
Restart the development client to load the new cabinet registration; F3+T only
reloads models and textures for an already registered cabinet.

## Verification

Build and all **141 server GameTests** passed on 2026-10-07. Eight new IIDX
tests cover all directions and sections, shared saved playback, single cabinet
and disc drops, neighboring-cabinet isolation, blocked placement, support loss,
world limits and walking across the platform. Catalog-wide tests cover its
material purchase and paid Arcade Pass use.

An independent geometry audit checks finite, nondegenerate surfaces, UVs,
texture references, collision coverage and the open space above the platform.
It verifies the clear recess in front of the upper backing. The split world
model preserves the item model's surface area.

The isolated native client verified all 192 block states, complete textures,
kiosk purchase with exact material deductions, survival placement, Arcade Pass
debit and rewards, disc insertion/ejection, independent neighbors and single
removal. GPU atlas samples confirmed actual turntable-frame changes before and
after resource reload. Final native views include the corrected rear backing,
side panels, visible woofer cones and e-amusement readers.

A copied client with Sodium 0.8.13, Iris 1.8.14-beta.1 and Complementary
Reimagined r5.9.3 (HIGH) also passed the model, texture-animation and resource
reload checks. Straight-on and elevated views verified clearance between the
lower screen artwork and its surround, and between the printed control deck
and its housing. The original pack and its saves were not modified.
