# Resource namespace

Current resources use the `japanesearcades` namespace. Earlier development
versions used a different namespace; the pre-release rename does not migrate
old item IDs or world data.

Portable authoring files, source textures, and runtime exports use the current
resource paths. Blender preview scenes are regenerated locally. Archived test
worlds, screenshots, and machine-specific verification records are not part of
the public source tree.
